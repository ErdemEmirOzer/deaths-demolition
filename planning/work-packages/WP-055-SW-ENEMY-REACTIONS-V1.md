- **Uygulama sözleşmesi:** `Damage/SpecialReaction` (`SpecialReactionKind` Push/Web/Pull, `SpecialReaction` readonly struct: kind, silah, yön, kuvvet, saniye, transaction; `ISpecialReactionReceiver`) — `IDamageReceiver`'ın yanında; silah `DamageTarget.Receiver as ISpecialReactionReceiver` ile ister, düşman tipini öğrenmez. `Enemies/ZombieSpecialReactions` (`SpecialReactionProfile` + `ZombieEnemy` partial) tier çözümünü yapar ve beat'i yükseltir.
- **Sayılar (PROTOTYPE-ONLY):** itme hızı = ImpactForce × 0,9 (tavan 4,5 m/s = WP-007 knockback tavanı) × direnç; sersemleme 0,45 s × direnç (Elite 0,225 / Ultra 0,09 s; `BeginStagger` + saldırı iptali; Runner'da `PlayStumble`); ağ hız çarpanı Standard 0 (kök) / Special 0,35 / Elite 0,55 / Ultra 0,75, süre = SealSeconds (6 s) × 0,35 / 0,25 / 0,20 / 0,15 → 2,1 / 1,5 / 1,2 / 0,9 s (yeni mühür uzun ağı kısaltmaz); çekim hızı = ImpactForce × 0,55 (tavan 3,2 m/s) tık başına merkeze doğru; Ultra çekilmez, tık süresince ×0,6 yavaşlar.
