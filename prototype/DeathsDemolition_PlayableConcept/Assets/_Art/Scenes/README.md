## WorldSource — which world the Run scene plays in (ADR-014-1)

`Run.unity` keeps its `WorldBootstrap`. On Awake it resolves `WorldSourceSettings` (`Assets/_Art/Resources/DD_WorldSource.asset`):

- `Procedural` — the M0 blockout is built at load (fallback, A/B reference).
- `AP005` — `World_AP005.unity` is loaded **additively** into Run; the active scene stays `Run`, so the HUD, the flow and every probe keep working unchanged, and the world scene's bootstrap installs the run systems on the AP-005 markers.

Override without touching the asset: command line `-ddWorldSource Procedural|AP005` (Player and Editor) or the environment variable `DD_WORLD_SOURCE` (tests, gate scripts). The resolved value is logged once (`[World] WorldSource = …`) and recorded by `PilotPerfProbe` (`worldSource` in `04-window.json`).

Layer policy (ADR-014-2): an instance flagged `occluder_candidate` or `fade_mesh` in the placement is entirely on `CameraOccluder` (fades for the camera and blocks bullets/aim like the procedural walls); every other instance is on `Environment`. The prefab-level family policy (WP-012) only applies where a prefab is placed by hand.
